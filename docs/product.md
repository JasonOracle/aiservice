# 产品需求文档 (PRD) - AI 客服 MVP

## 1. 产品愿景
打造一个轻量、现代、且具备极高技术含金量（**RAG 向量检索**、**Mem0 智能长期记忆**、**跨端无缝接力**）的开源 AI 客服展示项目。

## 2. 目标用户
- 需要将其部署在个人/公司网站，以提供智能问答的站长或开发者。
- 想要学习现代全栈 AI 架构 (Next.js + Python FastAPI + Ant Design X + TiDB Vector) 的学习者。

## 3. 核心功能流 (User Flows)

### 3.1 C端用户：商城体验与智能问答 (Web & Mobile)
为构建完整的业务闭环体验，C 端将被包装为一个简易的**“伪电商 App”**，并采用**“双端异构渲染”**的架构（PC端和移动端加载不同的组件树）：

**鉴权机制 (Auth Flow)**：
- 采用强登录态。用户必须通过手机号+密码登录后，才能浏览首页和客服（用于精确绑定 Mem0 记忆）。

**移动端 (Mobile) - 纯正原生体验**：
- 底部包含三个 Tab 导航：
  1. **首页 (Home)**：静态商品列表。
  2. **消息 (Messages)**：展示历史咨询会话的列表页。
  3. **我的 (Profile)**：极简的个人中心，数据作为 Mem0 冷启动上下文。
- **客服聊天室**：绝对沉浸式全屏流，输入框吸底。UI 组件采用 `antd-mobile` 构建。

**PC端 (Desktop) - 高效大屏界面**：
- 采用类似网页版 ChatGPT 的宽屏两栏/三栏布局。
- 左侧为历史记录导航，居中为聊天流和商品上下文展示区，右侧可呼出个人资料侧边栏。UI 组件采用 `antd` (Ant Design) 构建，保持与移动端、B端一致的企业级质感。

**跨端无缝接力 (QR Code)**：PC 端用户可点击“手机端继续”，生成带 Session ID 的二维码，手机扫码后直接进入该会话。

### 3.2 管理员后台 (Admin Dashboard - `tob` 项目)
- **入口**：独立的 B端项目（独立端口/域名），登录前需通过 `.env` 中的 `ADMIN_PASS` 极简鉴权。
- **框架布局**：标准的专业 B 端左侧边栏导航架构。
- **模块一：知识库大盘**
  - **Hero 区域**：带有渐变背景的科技感头部。
  - **核心指标卡片**：展示文档总数、切片数等。
  - **文档列表**：无硬实线边框的立体弥散阴影表格，提供文档上传（支持 PDF/Word）和“溯源测试”功能。
- **模块二：模型中心 (Model Center)**
  - **功能**：动态管理多通道 AI 模型网关。支持自定义 BaseURL 和 API Key。
  - **界面展现**：轻奢质感浅色流光渐变卡片网格。展示各通道的连通性延迟 (ms) 和当前主力模型，支持下拉更新并切换大模型，告别硬编码。
- **模块三：实时坐席监控 (Agent Workspace)**
  - **功能**：通过 WebSocket 实时监听 C 端用户产生的所有对话流。
  - **人机协同与双层 AI 托管**：
    - **双层托管开关**：顶部提供“全部 AI 对话托管 (全局)”开关，每个会话标题右侧提供“独立专属 AI 托管 Switch”；
    - **优先级仲裁**：对话专属 Switch 优先级高于全局开关。当会话关闭 AI 托管时，该客户由人工专属接待；处理完毕重新开启即交还 AI 托管；
    - **实时双向插话**：人工客服在 B 端输入内容发送后，通过 WebSocket 毫秒级直推 C 端客户端，以绿色客服身份无缝展示。

## 4. 界面与交互要求
- **极简与高级感**：参考 Vercel/Linear 的设计语言，运用大量的负空间、精准的灰度色彩体系、以及毛玻璃和阴影效果。
- **响应式**：聊天界面在 PC 端可居中展示（类 ChatGPT 布局），在移动端则占据全屏。
